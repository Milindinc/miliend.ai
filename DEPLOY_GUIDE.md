# 🚀 Deploy Milind's Labour Code Chatbot on Netlify
## One-time setup — takes 5 minutes!

---

## STEP 1 — Get Your Free Gemini API Key
1. Go to **aistudio.google.com**
2. Sign in with Gmail
3. Click "Get API Key" → "Create API Key"
4. Copy the key (starts with AIza...)

---

## STEP 2 — Create Free GitHub Account
1. Go to **github.com**
2. Click "Sign Up" — it's free
3. Verify your email

---

## STEP 3 — Upload This Folder to GitHub
1. Go to **github.com/new** to create a new repository
2. Name it: `labour-code-bot`
3. Click "Create Repository"
4. Click "uploading an existing file"
5. Drag and drop ALL files from this folder:
   - index.html
   - netlify.toml
   - netlify/functions/chat.js
6. Click "Commit Changes"

---

## STEP 4 — Deploy on Netlify (Free)
1. Go to **netlify.com** → Sign up free (use GitHub login)
2. Click **"Add new site"** → **"Import an existing project"**
3. Choose **GitHub** → Select `labour-code-bot` repo
4. Click **"Deploy site"** — wait 1 minute

---

## STEP 5 — Add Your Secret API Key (Most Important!)
1. In Netlify dashboard → go to **Site Settings**
2. Click **Environment Variables** → **Add Variable**
3. Key: `GEMINI_API_KEY`
4. Value: paste your AIza... key here
5. Click **Save**
6. Go to **Deploys** → Click **"Trigger deploy"** → **"Deploy site"**

---

## STEP 6 — Get Your Shareable Link!
Netlify gives you a free link like:
`https://amazing-milind-labourcode.netlify.app`

You can rename it to something nicer:
- Site Settings → Domain Management → Options → Edit site name
- Change to: `milind-labourcode`
- Your link becomes: `milind-labourcode.netlify.app` ✅

---

## STEP 7 — Share Everywhere! 🎉
- **WhatsApp HR Groups** → Paste the link
- **LinkedIn Post** → Share with a short description
- **Email** → Send to your HR network

No one needs an API key — they just click and chat!
